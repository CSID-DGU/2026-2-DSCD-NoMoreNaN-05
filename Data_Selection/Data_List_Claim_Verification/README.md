# Claim verification reference data

건강기능식품 claim을 제품·원료·질병 기준으로 검증할 때 사용하는 원천 데이터입니다.

| 파일 | 내용 | 레코드 수 |
| --- | --- | ---: |
| `health_functional_food_products.jsonl` | 건강기능식품 제품 상세 정보 | 46,165 |
| `functional_ingredient_status.txt` | 기능성 원료 인정 현황 | 1,155줄 |
| `individually_approved_ingredient_info.txt` | 개별인정형 원료 정보 | 1,260줄 |
| `disease_codes.jsonl` | 질병 코드 정보 | 34,861 |

원본 형식을 유지한 복사본이므로, 전처리 결과는 이 폴더 밖의 별도 파일로 생성합니다.
