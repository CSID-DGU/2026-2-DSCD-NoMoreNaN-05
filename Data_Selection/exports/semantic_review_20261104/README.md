# DB 근거를 대조한 의미 재검토 (2026-11-04)

원본 8,728개에서 ETC 1,241개를 제외한 7,487개를 집계함.
그중 전달본의 confirmed 제품에 연결되고 알려진 제조사 충돌 9건에 속하지 않는
Claim **537개**를 assistant가 문장/DB 근거와 대조하여 재검토함.
모든 7,487개를 개별 의미 검토한 결과가 아님. 나머지 6,950개는 v1 분류를 유지함.

제조사 미확인 항목을 자동 보류하지 않는 조건 변경도 포함됨.
이 조건 변경의 영향을 제외하고 제조사 정보가 있는 257개만 보면
UNCLEAR는 169개 → 41개, SUPPORTED는 42개 → 138개임.
따라서 전체 변화량을 의미 판정 모델의 성능 향상으로 해석하면 안 됨.

## 해석 기준

- Folic Acid/엽산, Vit B1/비타민B1, 원소기호/성분명 등 명확한 명칭 대응을 인정함.
- '혈행 건강' 같은 축약된 표현을 해당 제품의 인정 기능성 범위 내 건강 지원으로 해석함.
  이 판정은 치료·완치·확실한 효과 보장을 허용한다는 의미가 아님.
- 제품의 성분 종류 수, 일일 섭취 방법, 표시량 및 비타민D의 단위 변환을 함께 대조함.
- 식약처 원료 인정 섭취량과 제품 실제 표시량을 구분함.
- 최초·유일함, 임상시험 세부 지표, 브랜드 업력, 원료 공급사·버전 차이 등은 부족한 자료로 단정하지 않음.
- 알려진 제조사 충돌 9건의 제품 항목은 계속 제외함.
- 제조사 미확인만으로 모든 Claim을 보류하지는 않지만, 제품 연결은 독립 검증되지 않은 전제임.
- 여러 주장 중 일부만 부합하거나 더 구체적 효과가 추가된 경우 대체로 UNCLEAR로 유지함.

## 전체 집계

이전 규칙 분류를 유지한 항목까지 포함하면 SUPPORTED 244, UNCLEAR 5,979,
OUT_OF_SCOPE 1,246, DISCLAIMER 18, VIOLATION/OVERCLAIM 각 0.
전체 UNCLEAR는 79.86%임. 이 중 4,502개는 제품 미확정, 1,110개는 제품 미검색,
188개는 제품 참조 누락, 75개는 알려진 제조사 충돌에 따른 기존 보류임.
나머지 104개는 이번에 직접 검토했지만 근거가 부족하거나 비교가 불가능한 항목임.

위반/과장 0은 안전성·적법성 보장이나 전체 자료의 위반 부재를 뜻하지 않음.
특히 재검토하지 않은 항목의 누락을 보장하지 않음.
이 결과는 assistant의 조건부 판단이며 사람 정답 라벨/법률 판단/Mechanism A·B의 실측 정확도가 아님.

## 파일과 재현

- `reviewed_537.json`: 실제 의미 검토한 537개. 원문·판정·판정 이유·DB 컬럼/값 포함.
- `changed_claims.json`: 이전 분류에서 라벨이 바뀐 310개.
- `claims_reassessed.json`: 7,487개 전체. 537개만 새 검토를 반영하고 나머지는 이전 결과 유지.
- `summary.json`: 범위별 집계와 조건 변경을 분리한 통계.
- frozen input: `data/processed/semantic_review_20261104/reviewable.json`.
- 적용 코드: `python -m scripts.apply_semantic_claim_review`.

지원 판단의 DB 필드 값은 보강 SQLite의 해당 신고번호 행과 동일한지 검증함.
원본 전달 JSON과 보강 DB는 변경하지 않으며 effect를 포함한 원본 Claim 필드를 보존함.
외부 API와 NLI를 실행하지 않았고 GitHub로 자동 업로드하지 않음.
