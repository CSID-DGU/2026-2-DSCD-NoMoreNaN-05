## 적용한 기존 규칙

- 제품명 정확 일치, 관측된 브랜드 분리·결합 후 정확 일치, 전체 이름의 정규화 Damerau–Levenshtein 70점 이상 후보 검색을 적용함.
- 기존의 정확한 표기 대응 및 온전한 구절 검색을 적용함. API 호출, 신규 OCR, 영상 다운로드는 수행하지 않음.
- 법인·공장 표기 정리 및 승인된 제조사 PAIR로 제품명·회사 그룹을 구분함. 입력 제조사, 같은 제품 Claim의 명시적 제조사, 브랜드 보조 비교 순서를 유지함.
- 신고번호는 제품명·회사로 선택하지 못했을 때 보조적으로 사용함. 이번 입력의 신고번호는 모두 null임.
- 서로 다른 제품 후보를 임의 선택하거나, 회사 일치가 확인되지 않은 이름 단독 후보를 confirmed로 올리지 않음.
- 70점은 후보 검색 기준이며 실제 정답률 70%라는 의미가 아님. 별도 정답 대조를 하지 않았으므로 이번 결과는 정확도 평가가 아닌 규칙 기반 연결률임.

## 파일

- `claims_with_db.json`: 기존 합의 형식의 출력. confirmed / unresolved / not_found를 유지하고, confirmed에만 타입별 DB 자료를 연결함. `MAIN_FNCTN`에 DB의 `main_functionality` 원문이 포함됨. 원본 Claim 전부와 claim_type 배열, effect 등 값을 그대로 보존함. 이번 재매핑에서는 ETC도 삭제하지 않음.
- `product_mapping_audit.json`: 제품별 검색 경로·점수·후보 원본 행·선택된 제품 ID·실패 사유. 전달 JSON의 구조를 변경하지 않기 위한 별도 점검 자료임.
- `summary.json`: 집계 기준과 결과, 원본/DB SHA-256.
- `source_input.json`: 입력 원본 복사본.
