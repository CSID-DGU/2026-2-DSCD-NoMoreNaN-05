# 제품별 최장 영상 선택 및 URL 중복 제거

사용자 승인 기준: 제품별로 60초 이하인 가장 긴 영상 1개를 남김.

1. 기존 누적 724건에서 길이가 0초 초과 60초 이하인 영상만 대상으로 함.
2. 기존 제품 ID별로 가장 긴 영상 1개를 선택함: 143건.
3. 여러 제품이 같은 영상을 선택한 경우 URL은 하나만 남김: 17개 중복 기록 제거, 최종 126개 영상.
4. 길이가 같으면 기존 파일 순서의 첫 번째 기록을 유지함.

- `ad_video_urls.json`: 최종 영상 126개. 기존 출력 필드와 상태값을 변경하지 않음.
- `selection_audit.json`: 제품별 선택 143건과 같은 URL을 공유하는 제품들의 기록. 다른 제품과의 연결을 잃지 않도록 보관한 참고 자료.
- `summary.json`: 단계별 개수와 적용 기준, 원본 해시.

최종 영상 목록에서는 같은 URL의 첫 제품 기록을 대표로 남기며, 제품별 전체 관계는 참고 자료에 보존함.
제품 수 143개와 고유 영상 수 126개는 집계 단위가 다름.
원본 수집 파일은 수정하지 않음. API 재호출/추가 수집도 하지 않음.

재생성: `python scripts/select_longest_youtube_ads.py`
