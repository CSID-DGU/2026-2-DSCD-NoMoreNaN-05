# 복수 제품 후보의 제조사 비교 결과

제품명 검색에서 복수 후보가 나온 52개 영상 내 제품 항목을 대상으로 제조사 원문(기존 법인·공백 정리 포함) → 공장 표기 정리 → 승인 PAIR 순서로 비교함. 이전 단계에서 제조사가 일치하는 후보가 있으면 이를 우선하며, 여러 개가 남더라도 더 넓은 비교로 임의 선택하지 않음. PAIR는 제품명 정확 일치/브랜드 분리 후 정확 일치 경로에만 적용함. 원본 후보는 모두 보존함.

입력 제품 제조사와 Claim에서 확인한 제조사가 승인 PAIR로도 설명되지 않는 경우 선택하지 않음. 제조사 정보가 없거나 같은 제조사에 여러 제품 기록이 남는 경우에도 선택하지 않음.

전체 216개 영상의 제품 항목 289개 기준:

| 결과 | 개수 | 비율 |
|---|---:|---:|
| 원래 후보 1개 | 210 | 72.7% |
| 복수 후보 중 제조사로 추가 선택 | 28 | 9.7% |
| 제품 하나를 선택 가능 | 238 | 82.4% |
| 여전히 미해결 복수 후보 | 24 | 8.3% |
| 후보 없음 | 27 | 9.3% |

미해결 24개 중 제조사 정보 없음 20개, 제조사가 일치해도 여러 제품 기록이 남음 2개, 입력 제조사 정보 충돌 2개임. 원래 단일 후보 210개에는 제조사 불일치가 허용된 검색 결과도 포함되므로, 82.4%는 독립적인 정답 정확도가 아닌 단일 제품 선택 가능 비율임. 제품 후보 자체가 있는 비율은 이전과 같은 262/289=90.7%임.

선택된 제품 항목에 속한 Claim은 2,912개/3,400개임. Evidence 검색이나 main_functionality 전달 JSON 생성은 이 실행에 포함하지 않음. 34개 회귀 테스트 통과함.

실행: `.\.venv\Scripts\python.exe scripts/disambiguate_product_candidates.py`

출력: `data/processed/product_identity_disambiguated/product_matches.json`, `summary.json`.
