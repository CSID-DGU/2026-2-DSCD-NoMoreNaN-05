# 70점 검색 이후 표기·축약·누락 이름 보완

대상: claims_all_real.json의 1,066개 제품 항목 중 70점 규칙으로 후보가 없었던 212개. 기존 후보/선택 결과와 원본 입력은 변경하지 않음. 기존 추론 작업이나 Evidence 검색을 재개하지 않음.

## 적용

- 표기: Unicode 호환 문자·상표 기호·괄호와 한자(한글) 병기 정리. 숫자·단위·+·%를 보존함. 영문 대응은 DB의 명시적 영문 병기 또는 동일 단일제품 영상에서 실제 관찰한 한글 이름만 사용함. 임의 번역은 사용하지 않음.
- 축약: 온전한 구절 포함/역포함 검색. 짧은 이름은 입력 브랜드를 붙여 검색 범위를 제한함. '유산'을 '유산균' 안에서 찾는 단어 내부 일치나 브랜드를 버린 '키즈 골드' 전체 DB 검색은 허용하지 않음.
- 누락: 동일 product_ref의 Claim, 수집 캐시의 실제 영상 제목·설명, 한국어 Windows OCR로 처리한 공개 썸네일 16장을 확인함. 원본 영상 전체 프레임 OCR·ASR·영상 다운로드는 수행하지 않음.
- 일반 원료/기능 표현을 제품명으로 오인하지 않도록 DB 원료명, 입력의 원료 필드, 추가 일반명 보호 규칙을 적용함. 같은 영상에 제품이 여러 개 있으면 제목만으로 제품 참조를 임의 배정하지 않음. 다른 제품과 브랜드가 구분되지 않는 누락 항목은 보류함.
- 복원 후보는 모두 검토 대상으로 표시하고 원문 출처를 기록함. 후보 복원과 제품 동일성 확정은 구분함.

## 결과

| 항목 | 이전 70점 | 보완 후 |
|---|---:|---:|
| 후보가 있는 제품 항목 | 854 (80.1%) | 903 (84.7%) |
| 제품 하나 선택 가능 | 688 (64.5%) | 713 (66.9%) |
| 후보 없음 | 212 | 163 |

추가 49개: 브랜드 범위를 유지한 구절 검색 45개, 같은 단일제품 영상에서 관찰한 영문/한글 제품명 대응 1개, 누락 이름의 제목/설명 기반 복원 3개. OCR은 16장 실행했으나 OCR만으로 추가 연결된 항목은 0개임. 한자/기호 정리만으로 이번 미연결 집합에서 추가된 항목은 0개임.

예: 입력 TruVitamin X™ → 동일 영상 제목 '트루바이타민 X™ 다니엘헤니 CF' → DB '트루바이타민 X'. 제목의 X를 보존하며 기본 제품 '트루바이타민'으로 대체하지 않음.

결과는 `data/processed/product_functionality_handoff_real_t70_recovered/`에 저장함. `mapped_products.json`에는 713개 제품 항목 및 해당 Claim 6,733개와 DB main_functionality 원문을 포함함. `all_results.json`에는 원본 9,638개 Claim이 보존됨. 추가 후보의 출처는 `recovered_candidates.json` 및 product.match.recovery_sources에서 확인함.

기존 후보/선택 product_id 보존, Claim 원문 보존, DB 기능성 원문 일치를 검증함. 관련 회귀 테스트 28개 통과함. 위 비율은 정확도가 아닌 검색/선택 가능 비율임.

실행: `.\.venv\Scripts\python.exe scripts/recover_product_candidates.py`
