# 제품명·제조사 표기 정리 비교

기존 216개 영상 / 3,400개 Claim의 저장된 제품 정보를 대상으로 제품 식별만 재실행함. Evidence 검색이나 모델 추론은 실행하지 않음. 원본 DB 및 기존 매핑 결과를 덮어쓰지 않음.

## 규칙

1. 기존의 공장 단위 비교로 유일하게 연결되면 그 결과를 우선 보존함.
2. 연결 실패 시 별도 비교용 제조사 키에서 법인 표기와 끝에 붙은 공장·지점·사업부문·사업부·사업장 표기를 정리함. 원문은 보존함. 분리된 접미부와 숫자 공장 표기를 처리하며, 모든 업체 별칭을 추측해서 합치지 않음. 공장 앞의 분리된 지명은 코드의 명시 목록만 처리함.
3. `서흥`과 `서흥헬스케어`처럼 법인명이 다른 경우는 합치지 않음.
4. 신고번호/전체 이름 정확 일치 → 온전한 구절 포함 + 제조사 → 전체 이름 Damerau–Levenshtein 80점 이상 + 제조사 순서로 검색함. 기존의 알려진 신고번호 충돌은 무시하지 않음.
5. 점수 = 100 × (1 − 편집 거리 / 두 전체 이름 중 긴 이름의 문자 수). NFC·대소문자·공백을 정리하며, 부분 구간의 점수로 대체하지 않음. 80점은 실험 기준이며 정확도 80%라는 의미가 아님.
6. 공장 표기 정리 후에도 제품 후보가 여러 개면 하나를 임의 선택하지 않음. 확인된 제조사가 없는 생략·오타 검색은 자동 연결하지 않음.

## 비교 결과

| 항목 | 기존 | 정리 후 |
|---|---:|---:|
| 제품이 식별된 Claim | 2,427 | 2,589 |
| Claim 기준 연결률 | 71.4% | 76.1% |
| 미연결 Claim | 973 | 811 |

새로 연결된 영상 내 제품 항목은 14개(13개 영상), 이에 속한 Claim은 162개임. 기존 2,427개 Claim의 연결 product_id는 모두 유지됨. 신규 연결은 모두 제품명 정확 일치 경로임. 전체 연결 결과 중 편집 거리 경로는 3개 Claim이며 생략 경로는 9개 Claim임.

예: `(주)네추럴웨이` ↔ `주식회사 네추럴웨이 포천 제2공장`, `(주)노바렉스` ↔ `주식회사 노바렉스2공장`의 표기 차이를 정리함.

## 정확도 해석

76.1%는 연결률이며 정답 정확도가 아님. 독립적인 정답 라벨이 없어 정밀도 수치는 산출하지 않음. 같은 법인의 공장이 달라도 제품 버전·신고 기록이 다를 수 있음. 신규 연결은 검토 대상으로 표시하며, 광고 포장/설명/신고번호와 실제 제품 동일성을 확인해야 함. `new_matches_review.csv`의 14개 항목을 사람이 정답/오답으로 검토하면 신규 연결의 정밀도를 계산할 수 있음. Claim 162개는 독립적인 제품 식별 실험 162건이 아님.

실행:

```powershell
.\.venv\Scripts\python.exe scripts/compare_product_identity_filters.py
```

출력: `data/processed/product_identity_filtered/summary.json`, `product_matches.json`, `new_matches_review.csv`.

기존 Evidence 파이프라인은 기존 제조사 비교 규칙을 기본값으로 유지하며, 이 실험 규칙은 별도 제품 식별 스크립트에 적용됨.
