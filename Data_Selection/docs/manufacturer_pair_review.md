# 제조사 검색용 PAIR 검토 목록

DB 제품 정보와 현재 영상의 제품 식별 결과에서 추출한 후보임. 실제 동일 법인·계열 관계·상호 변경 사실을 외부 자료로 확인한 목록은 아님. 사용자 승인으로 아래 1~10번을 `configs/manufacturer_pairs.json`에 등록함. '제품 검색에서 함께 비교하는 이름'으로 사용하며 원본 제조사명은 보존함.

|---|---|---|---|

| 3 | 대한홍삼 | 대한홍삼진흥원 | DB 양쪽의 공통 제품명 6종. 회사명에 공통 핵심 문자열이 있음. |

| 9 | 다원바이오 | 다원바이오텍 | DB에 두 이름 모두 존재함. 공통 제품명은 0종. |

공통 제품명 수는 공장·법인 표기 정리 후 각 제조사 그룹의 전체 제품명(NFC·대소문자·공백 정리) 교집합의 개수임. 일반명·수출용 제품도 포함하므로 동일 회사의 증거로 단독 사용하지 않음.

## 자동으로 같은 제조사로 묶지 않을 불일치 사례

| 입력 제조사 | DB 제조사 | 현재 영상의 제품명 |
|---|---|---|
| 녹십자웰빙 | 알피바이오 | 관절연골엔 구절초 |
| 아모레퍼시픽 | 풀무원건강생활 | 메타그린 |
| 크리스찬한센(Chr.Hansen) | 빅솔 | 엘레나 |
| 노바렉스 | 비오팜 | 트루바이타민 |

이 사례들은 입력 역할 혼동, 위탁 제조, 제조사 변경 등 별도 확인이 필요하며 이름 별칭으로 자동 병합하지 않음.

## 채택 후 적용 방식

제품명이 정확히 일치하고, 사용자가 승인한 PAIR로 제조사를 비교했을 때 후보가 하나면 연결함. 신고번호 충돌은 무시하지 않으며 여러 신고 기록이 남으면 자동 선택하지 않음. 제품명도 오타인 경우까지 함께 완화하는 규칙은 별도 검토함. PAIR는 전이적으로 확대하지 않음(A↔B, B↔C 승인으로 A↔C를 자동 승인하지 않음).

전체 기계 추출 결과는 `data/processed/product_identity_filtered/manufacturer_pair_candidates.json`에 저장함. 광범위한 문자열 유사 후보와 단순 불일치도 포함된 70쌍이므로, 이 문서의 검토 목록과 구분해서 사용함.
