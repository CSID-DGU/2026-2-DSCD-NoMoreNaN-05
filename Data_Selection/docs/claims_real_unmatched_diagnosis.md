# 새 입력 미연결 제품 사유 분석

대상은 claims_all_real.json의 제품 항목 1,066개 중 후보가 없는 293개임. 기존 제조사 필수 검색의 실패 사유를 그대로 재사용하지 않고 현재 완화 검색에서 실제 DB 이름을 재비교함. 이 단계에서는 검색/매핑 규칙과 기존 전달 JSON을 변경하지 않음.

| 사유 | 제품 항목 수 |
|---|---:|
| 정확 일치가 없고 전체 이름 최고 점수가 80점 미만(아래 부분 구절 그룹 제외) | 221 |
| 부분 구절 후보는 있으나 현재 규칙에서 채택되지 않음 | 44 |
| 제품명 자체가 null/비어 있음 | 23 |
| 홍삼정 등 일반명 보호 규칙에 해당 | 5 |
| 합계 | 293 |

221개 중 최고 점수 70~80 미만은 63개, 50~70 미만은 127개, 50 미만은 31개임. 점수만 낮춘다고 정답이 확보되는 것은 아니며, 다른 제품이 최고 점수를 받을 수 있음.

부분 구절 44개에는 '데일리', '베이비', 브랜드를 뺀 '키즈 골드'처럼 다른 제품도 다수 포함될 수 있는 검색어가 있음. 이 구절들이 DB에 존재한다는 사실을 원래 제품이 DB에 존재한다는 증거로 취급하지 않음. 현재 후보 검색은 제조사 불일치/미확인을 허용하므로 기존 strict 제조사 누락 사유를 주된 미연결 원인으로 보고하지 않음.

## 개선 우선순위

1. 입력 brand_name + product_name 재결합 후 정확 일치 검색: 기존 미연결 18개에서 후보를 찾음. 예: '맘엔맘엔 오메가3' + '락피도' → DB '락피도 맘엔맘엔 오메가3'. 브랜드 분리만 수행했던 현재 규칙에 반대 방향을 보완할 수 있음.
2. 한자/괄호 등 표기 대응: 2개에서 후보를 찾음. 예: '홍삼정 현' → '홍삼정 賢(현)'. 숫자·용량·제형까지 무차별 삭제하지 않고 대응 표기만 검토해야 함. 진단 코드는 문자 제거 후 이름이 같아지는지를 탐색했으며 아직 공식 정규화 규칙으로 적용하지 않음.
3. 두 방법의 중복 없는 잠재 후보는 20개. 후보 검색 범위는 773개(72.5%)에서 793개(74.4%)로 확대될 여지가 있지만, 아직 실제 매핑 규칙 적용/동일 제품 확인은 수행하지 않음.
4. 제품명 null 23개는 영상의 제품 포장/OCR/자막 등에서 제품명을 다시 확보해야 함. 브랜드만으로 제품을 고르지 않음.
5. 부분 구절 44개와 영문/한글 이름 차이는 별도 후보 검색 후 제조사/제품 구분 정보를 확인해야 함. 80점 일괄 하향으로 처리하지 않음.
