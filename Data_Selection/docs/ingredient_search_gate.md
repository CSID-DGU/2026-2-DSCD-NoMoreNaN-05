# 원료 근거 검색 조건 변경

제품 미식별을 이유로 원료 검색을 자동 실행하던 경로를 제거함. URL에 속한 Claim 중 동일한 product_ref의 제품이 해당 원료를 사용·함유·포함·배합·첨가한다고 명시한 경우에만 원료 근거 검색을 허용함.

- `COMPOSITION` Claim 또는 '이 제품/본 제품/제품에는/제품은'처럼 제품을 명시한 문장에서 긍정 함유·사용 표현을 확인함.
- 원료명이 실제 문장에 나타나야 함. ingredients 필드만 채워졌거나 제품명·DB 기능성에 원료명이 있다는 이유로 검색하지 않음.
- 단순 원료 효능 문장, 부정·조건·질문 표현은 검색 조건으로 사용하지 않음. 현재 보수적인 규칙 기반 탐지이며 모든 자연어 표현을 이해하는 모델은 아님.
- 같은 URL이라도 다른 product_ref의 함유 주장을 가져오지 않음.
- 함유 주장 Claim의 ID와 관찰한 원료를 기록함. 이후 동일 제품의 Claim에서 해당 원료 참고자료를 후보로 사용할 수 있음.
- 광고의 함유 주장은 관찰 정보이며 실제 함유가 검증됐다는 의미는 아님.

제품 후보 연결 결과(289항목 중 262항목, 90.7%)는 유지됨. 새 조건으로 3,400개 Claim의 후보 존재 여부를 재집계한 결과 제품 자료 후보가 있는 Claim은 3,226개(94.9%), 제품 미연결 상태에서 원료만으로 보완된 Claim은 0개, 근거 후보 없음은 174개임. 함유·사용 주장에 의해 원료 검색 조건을 충족한 Claim은 353개이며 모두 제품 자료 후보가 있는 범위에 속함.

기존 무조건 원료 보완으로 계산했던 56개 및 96.5%는 이전 규칙의 결과이며 현재 결과로 사용하지 않음. 최신 집계는 `data/processed/product_identity_relaxed/evidence_availability_declaration_gated.json`에 저장함. 예전 결과는 이력으로 보존함. 실제 전체 재순위 추론/Top-1 선정은 실행하지 않음.

실행: `.\.venv\Scripts\python.exe scripts/summarize_declaration_gated_availability.py`

새 후보 생성부터 `pipeline_version=2`로 구분해 예전 후보 파일을 자동 재사용하지 않도록 함.
